# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the impact you expect.

You'll get an acknowledgement within 7 days. Fixes for confirmed issues ship as a patch release, and you'll be credited in the changelog unless you'd rather not be.

## Supported versions

Only the latest release on the default branch of each repository receives security fixes.
